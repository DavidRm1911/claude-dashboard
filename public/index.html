AUDITORÍA

Espacio y respaldo de tus repos

Tamaño en disco, hace cuánto no tocas cada repo y si ya está respaldado en GitHub. Si el repo tiene cambios sin commitear, el botón dice "Commit + push" — hace git add -A + un commit de snapshot antes de subir, para que quede todo respaldado. "Borrar local" solo se habilita cuando el repo ya está 100% respaldado, y pide que escribas el nombre para confirmar.

¿DE DÓNDE SALE ESTA INFO?

Tokens y sesiones: leo directamente los archivos .jsonl de cada sesión en ~/.claude*/projects/** — cada línea trae el usage real que devolvió la API por turno.
Costos: estimación con la tabla de precios de Anthropic (junio 2026); no son montos facturados reales.
Cuentas: leo el campo oauthAccount de cada .claude.json (email, organización, tipo de cuenta).
Skills: recorro skills/ y plugins/marketplaces/ de cada perfil y parseo el frontmatter de cada SKILL.md.
Historial: leo ~/.claude*/history.jsonl, cada línea es una entrada del CLI.
Todo se recalcula en cada carga (con una caché de 8s para no ralentizar el auto-refresh); nada se envía a internet.
